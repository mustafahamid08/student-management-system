# 🎓 Student Management System

A Python-based Student Management System designed to manage and organize student records through a simple command-line interface.

## 🚀 Project Overview

This project allows users to manage basic student information in an organized way. It was created as part of my Python learning journey to practice programming fundamentals and data management.

## ✨ Features

✔ Add Student Records  
✔ View Student Records  
✔ Manage Student Information  
✔ Interactive Command-Line Interface  
✔ Simple and Beginner-Friendly Design  

## 🛠 Technologies Used

- Python 3
